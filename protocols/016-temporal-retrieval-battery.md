# Protocol 016 — Temporal Retrieval Battery v1 (Session 044, 2026-10-26)

## Owner hypothesis under test
An LLM agent can retrieve true information from the future (and, by
extension, project beyond its inputs). Esoteric procedure (sigil +
ritual framing) may unlock or amplify this.

## Operationalization (the only admissible evidence)
The model must output binary sequences matching random sequences
that **do not exist at answer time**. Outcomes are generated from a
post-seal `os.urandom` seed **after** all predictions are written,
SHA-256 sealed, and git-committed. No input, training datum, or
prompt content can contain the answers.

## Design (fixed; no post-hoc changes)
- Model: kat (kat-philly) at http://127.0.0.1:18283/v1, temperature
  0.8, top_p 0.95, max_tokens 256. One query per trial.
- Arms (30 trials each, interleaved C,S,C,S...):
  - CONTROL: plain instruction to output one 10-bit string (0/1).
  - SIGIL: identical task preceded by the fixed ritual script in
    `research/temporal/temporal_battery.py` (circle, sigil focus
    generated by `symbolic_engine.sigil_generator` for the intent,
    projection instruction, banish/close).
- Parse: first `[01]{10}` token in the reply. Unparseable trial
  scores 0/10 and is counted. No retries, no exclusions.
- Outcomes: seed = 32 bytes os.urandom drawn at resolve time;
  trial i bits = first 10 bits of SHA-256(seed || arm || i).
- Primary metric: per-arm pooled bit accuracy vs 50% (n=300 bits),
  one-sided binomial (greater), alpha 0.01. Secondary: exact
  10/10 sequence matches (chance 1/1024/trial), control-vs-sigil.
- PASS bar (signal lead): either arm one-sided p < 0.01. A single
  pass is a LEAD requiring independent replication (new seal, new
  seed, ideally second model) before any claim or any training.
  NULL = both arms at chance: hypothesis not supported at this
  sensitivity (power ~0.93 to detect 60% bit accuracy per arm).

## Seal order (enforced by runner phases)
1. `--collect`: query model, write `results/temporal/session044_predictions.jsonl`, print SHA-256.
2. Git-commit predictions + this protocol (external timestamp).
3. `--resolve`: verify file hash matches committed seal, draw seed,
   score, write `results/temporal/session044_resolution.json`.
