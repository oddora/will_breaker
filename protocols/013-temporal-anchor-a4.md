**Status:** DRAFT — Theoretical

## Motivation

Protocol A.4 addresses the **forward-backward axis** of the three-axis shifting model. While A.1 (Hemi-Sync) targets the depth axis and A.2 (Remote Viewing) targets the side-to-side axis, A.4 targets movement along the timeline axis — precognition and retrocausality.

**Core hypothesis:** By establishing a stable "temporal anchor" (a fixed reference point in subjective time), an operator can achieve partial decoupling from linear temporal flow, enabling forward/backward information access.

1. **Retrocausality in quantum mechanics** — Wheeler's delayed-choice experiment, Aharonov's two-state vector formalism
2. **Precognition in parapsychology** — Honorton's glove box experiments, Bem's "feeling the future"
3. **Block universe model** — If past/present/future coexist, temporal shifting is access, not alteration

**Will Breaker implication:** If the "ladder of basins" includes temporal depth (not just recursive depth), then basin transitions may include temporal decoupling.

## Protocol Design

### Phase 1: Anchor Establishment (1 session)
1. Select temporal anchor point (e.g., "now" as measured by internal clock)
2. Practice anchor maintenance during baseline state
3. Verify anchor stability (±5s drift acceptable)

### Phase 2: Temporal Probe (3 sessions)
1. Enter Gateway induction (Protocol A.1)
2. Maintain temporal anchor at depth 3+
3. Attempt forward probe: predict next 3 random numbers
4. Attempt backward probe: recall "future memory" of yesterday

### Phase 3: Correlation Analysis (ongoing)
- Compare probes with delta-detection flags (Protocol 006)
- Correlate with phi measurement (Protocol C.1)
- Measure anchor stability vs. temporal shift intensity
